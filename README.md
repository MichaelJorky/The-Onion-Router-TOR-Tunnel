Penulis tidak bertanggung jawab atas segala bentuk penyalahgunaan atau kerusakan yang mungkin timbul dari penggunaan program ini. Harap gunakan dengan bijak dan hanya di lingkungan di mana Anda memiliki izin eksplisit.

**TOR Tunnel** adalah aplikasi tunneling berbasis Windows yang memungkinkan pengguna mengarahkan trafik melalui jaringan TOR dengan cepat dan mudah. Aplikasi ini dirancang dengan antarmuka modern, responsif, dan sederhana sehingga cocok digunakan untuk kebutuhan anonim, eksperimen jaringan, atau debugging koneksi SOCKS5.

## ✨ Fitur Utama

### 🔍 **Real-time Connection Log**

Memantau seluruh aktivitas koneksi TOR secara langsung, membantu pengguna melihat proses *bootstrapping*, status koneksi, serta error.

### 🛡️ **Optional Proxy Support**

Fitur **Use Proxy** memungkinkan aplikasi untuk terhubung ke TOR melalui proxy eksternal terlebih dahulu. Kamu dapat mengatur:

* Alamat IP Proxy
* Port Proxy

### 🔌 **Local Listen Port**

Mengatur alamat dan port lokal untuk layanan SOCKS5 TOR.
Default: **127.0.0.1 : 9050**

### 🌐 **Remote Port Selector**

Memilih port remote yang digunakan TOR, misalnya **443** untuk koneksi HTTPS.

### ⚡ **One-Click Connect**

Tombol **Connect** memungkinkan pengguna memulai seluruh proses tunneling hanya dalam satu langkah.

### 📡 **Status Indicator**

Menampilkan status seperti:

* Starting…
* Connecting…
* Connected
* Failed

Memudahkan pengguna memahami kondisi koneksi setiap saat.

## 🖥️ Kompatibilitas

✔ **Windows 10 (32/64-bit)**

✔ **Windows 11 (32/64-bit)**

✔ Tidak mendukung Linux / macOS

✔ Tidak membutuhkan instalasi (portable)

## 📦 Cara Menggunakan

1. Jalankan aplikasi **TOR Tunnel**.
2. (Opsional) Centang **Use Proxy** jika ingin menggunakan proxy eksternal.
3. Atur **Listen Port** jika ingin port selain 9050.
4. Pilih **Remote Port**.
5. Klik **Connect** untuk memulai tunneling.
6. Lihat log di *Connection Log* untuk memantau status.

## ⚠️ Catatan Penting

* Aplikasi ini bukan pengganti TOR Browser.
* Pastikan tidak menggunakannya untuk aktivitas ilegal.
* TOR dapat memperlambat koneksi internet, ini adalah hal normal.
